# Theme sample provenance

These are approved marketing examples, never customer uploads. Each sample manifest records the source of every optimized card.

- Existing hero examples: [source and photographer manifest](../../example-images/MANIFEST.md). Source photos use the linked Unsplash/Pexels licenses; illustrations reuse the approved production examples.
- Halloween: [photo URLs and licenses](halloween-sources.json). The matching source photos were illustrated through the authorized image API.
- Additional occasions: [generated sample provenance and prompts](generated-samples.json). These depict fictional people, generated with the user's permission using gpt-image-2. Model, source, illustration, and prompts are retained per sample.
- Display fonts: distribution licenses are in `public/fonts/themes/*-OFL.txt`.

Production details stay here, outside the customer-facing images.
