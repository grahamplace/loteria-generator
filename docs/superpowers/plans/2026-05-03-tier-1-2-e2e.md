# Tier 1 + Tier 2 E2E Test Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 11 Playwright tests covering the core revenue, auth, and board-editor workflows of the Lotería generator, building on the existing E2E foundation.

**Architecture:** Shared seeded user (`e2etest@example.com`) with per-test board isolation. Direct DB seeding via Drizzle for cards/boards (no real upload). Stripe unlock tested via signed webhook fixture, not the hosted checkout UI. Cards complete synchronously via `NEXT_PUBLIC_SKIP_AI_PROCESSING=true` (no Inngest needed in tests).

**Tech Stack:** Playwright 1.59, Drizzle ORM, Neon HTTP driver, better-auth, Stripe SDK (signing only).

**Spec:** `docs/superpowers/specs/2026-05-03-tier-1-2-e2e-design.md`

import { db } from './db';

export async function getUserIdByEmail(email: string): Promise<string> {
  const rows = await db.select({ id: user.id }).from(user).where(eq(user.email, email)).limit(1);

  // ON DELETE CASCADE on cards.board_id handles cards.

  await db.delete(user).where(eq(user.id, userId));
}

export interface SeedBoardOpts {
  userId: string;
  name?: string;
  isUnlocked?: boolean;
}

export async function seedBoard(opts: SeedBoardOpts): Promise<{ id: string; name: string }> {
  const name = opts.name ?? `E2E Board ${Date.now()}`;
  const [row] = await db
    .insert(boards)
    .values({
      userId: opts.userId,
      name,
      isUnlocked: opts.isUnlocked ?? false,
    })
    .returning({ id: boards.id, name: boards.name });
  return row;
}

```ts
import { stripe } from '@/lib/stripe';
import type { APIRequestContext } from '@playwright/test';
import { buildCheckoutCompletedEvent } from '../fixtures/stripe-checkout-completed';

export interface UnlockOpts {
  boardId: string;
  userId: string;
}

export async function unlockBoardViaWebhook(
  request: APIRequestContext,
  opts: UnlockOpts
): Promise<void> {
  const secret = process.env.STRIPE_WEBHOOK_SECRET;
  if (!secret) throw new Error('STRIPE_WEBHOOK_SECRET required for unlock helper');

  const event = buildCheckoutCompletedEvent({ boardId: opts.boardId, userId: opts.userId });
  const payload = JSON.stringify(event);
  const signature = stripe.webhooks.generateTestHeaderString({ payload, secret });

  const res = await request.post('/api/stripe/webhook', {
    headers: {
      'stripe-signature': signature,
      'content-type': 'application/json',
    },
    data: payload,
  });
  if (!res.ok()) {
    throw new Error(`Webhook returned ${res.status()}: ${await res.text()}`);
  }
}
```

import { eq } from 'drizzle-orm';
import { boards } from '@/db/schema';
import { db } from './helpers/db';
import { deleteBoardsForUser } from './helpers/cleanup';
import { getUserIdByEmail } from './helpers/get-user-id';

const SEEDED_EMAIL = 'e2etest@example.com';

test.describe('board unlock via webhook', () => {

  let boardId: string;

    await page.goto(`/boards/${boardId}`);

    await unlockBoardViaWebhook(request, { boardId, userId });

    const [row] = await db
      .select({ isUnlocked: boards.isUnlocked })
      .from(boards)
      .where(eq(boards.id, boardId))

## Cross-cutting notes for the implementer

**Worktree:** Implementation runs in `.claude/worktrees/e2e-testing-foundation` on branch `worktree-e2e-testing-foundation`. Don't switch branches.

**Local dev server:** The Playwright config's `webServer` block starts `next dev --port 3006`. Tests run against that. If a dev server is already running on 3006 (e.g., from prior manual testing), stop it before running e2e — the orchestrator's `webServer.reuseExistingServer` config governs whether it's reused.

**Env precedence:** The orchestrator script (`scripts/e2e-run.ts`) loads `.env.test` and overrides `DATABASE_URL` with the ephemeral branch URL. Anything in `.env.local` is also loaded by Next.js itself; for the e2e Stripe + skip-AI flags, prefer `.env.test` so they only apply during e2e.

**Selector stability:** Prefer `getByRole({ name })` over CSS selectors. The aria-label additions in Task 4 cover the three known gaps; if you discover another, add an aria-label rather than a `data-testid`.

**Cleanup philosophy:** Every test file MUST clean up the seeded user's boards in both `beforeEach` and `afterEach` so the file is order-independent and so a crash mid-file doesn't pollute the next file.

**No window.confirm:** The CLAUDE.md / browser-automation rule prohibits triggering native dialogs. All confirmations in this app use shadcn `AlertDialog` — verify this if you add new flows.

**Per-test timeouts:** Most tests should pass within Playwright's 30s default. The export test bumps to 60s due to PDF generation.

**If a test is flaky:** First reproduce locally with `--retries=0`. If it's a real race, use `expect.poll()` rather than `page.waitForTimeout()`.
